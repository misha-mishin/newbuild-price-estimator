# Учебный датасет: цены на квартиры в новостройках

**Дата получения индексированных страниц:** 12.11.2026.  
**Объём:** 804 строки, 41 жилой комплекс, 3 девелопера.  
**Файлы:** `newbuild_prices.csv` для Python/ML; `newbuild_prices.xlsx` для просмотра и фильтрации в Excel.

## Источники и ограничения

Данные извлечены из публично индексированных страниц каталогов застройщиков:

| Застройщик | Строк | Домены источников |
|---|---:|---|
| ПИК | 214 | https://www.pik.ru |
| ГК ФСК | 185 | https://fsk.ru |
| Level Group | 405 | https://level.ru |
| **Всего** | **804** | |

Для каждой строки сохранён `source_url`. В каталоге ПИК иногда нет уникального идентификатора квартиры; такие строки дедуплицированы по комбинации ЖК, корпуса, площади, этажа и цены. В каталогах ФСК и Level доступны идентификаторы квартир.

**Это не одновременный рыночный срез.** Поле `retrieved_on` означает дату получения поискового индекса, а `source_crawled_age` — относительный возраст проиндексированной страницы. Некоторые страницы ПИК были проиндексированы несколько месяцев назад; у ФСК и Level большинство страниц свежее. Цены могли измениться, квартиры могли быть проданы или забронированы. В выборке представлены **цены предложений**, а не фактические цены сделок.

Каталоги показывают различные промоусловия. `asking_price_rub` — отображённая цена на странице. В `original_price_rub`, если он есть, сохранена более высокая перечёркнутая / базовая цена. Точные условия сделки не гарантированы. Поле `discount_pct` рассчитано исключительно для анализа и не должно быть входным признаком для модели текущей цены.

Перед передачей датасета внешним кандидатам проверьте условия использования и распространения данных соответствующих сайтов. Набор предназначен для учебного задания, а не для коммерческих решений о ценообразовании.

## Словарь полей

| Столбец | Описание |
|---|---|
| `record_id` | Технический ID строки в этой выборке, не ID квартиры на сайте |
| `developer` | Название застройщика |
| `project` | Название ЖК, как в источнике |
| `project_group` | Комбинация застройщика и ЖК для GroupKFold / GroupShuffleSplit |
| `building`, `section` | Корпус и секция (если есть) |
| `listing_number` | ID/номер квартиры из источника, если удалось извлечь |
| `id_quality` | `source_listing_id` или `catalog_surrogate` (ID объекта отсутствует) |
| `rooms` | Комнатность; **0 = студия** |
| `area_m2` | Площадь квартиры в квадратных метрах |
| `floor`, `floors_total` | Этаж квартиры и общее число этажей, если опубликовано |
| `finish` | Тип отделки, если указан |
| `handover_text` | Срок заселения или статус сдачи в исходной формулировке |
| `asking_price_rub` | Выбранная отображённая цена квартиры, руб. |
| `asking_price_per_m2_rub` | Цена за м²: опубликованная или рассчитанная как `asking_price_rub / area_m2` |
| `price_per_m2_kind` | `published` для ПИК/ФСК или `calculated` для Level |
| `original_price_rub` | Более высокая цена до скидки, когда она опубликована |
| `discount_pct` | Расчётная скидка относительно `original_price_rub`, % |
| `source_kind` | Страница каталога или карточка конкретной квартиры |
| `source_url` | Страница застройщика, на которой была размещена запись |
| `source_crawled_age` | Относительный возраст индексированной копии страницы |
| `retrieved_on` | Дата получения индексированной информации, не дата объявления |

Пустые поля — отсутствующие данные. Не заменяйте их нулями без обоснования.

## Проверки исходного CSV

- 804 записи, 41 уникальная пара `(developer, project)`.
- 0 записей с некорректной площадью, этажом, ценой или URL по применённым правилам.
- Проверена согласованность опубликованной цены за м² с `asking_price_rub / area_m2` (допуск 2,5%).
- Количество комнат: студии — 99; 1-комнатные — 316; 2-комнатные — 220; 3-комнатные — 130; 4-комнатные — 39.
- Пропуски: `finish` — 592; `floors_total` — 190; `listing_number` — 193; `handover_text` — 410.

## Рекомендации для тестового задания

Цель модели: прогноз **цены предложения за м²**. Можно обучать модель на `log(asking_price_per_m2_rub)` и обратным преобразованием получать прогноз в рублях.

**Утечка целевой переменной:** если прогнозируется цена за м², нельзя использовать как признаки `asking_price_rub`, `asking_price_per_m2_rub`, `original_price_rub` и `discount_pct`. `record_id`, `listing_number` и `source_url` тоже не следует использовать напрямую как признаки.

Не ограничивайтесь случайным train/test split: **проверяйте качество на ЖК, не встречавшихся при обучении**, используя `project_group`. Отдельно оценивайте качество по девелоперам и комнатности. Сравните с простым baseline, например медианной ценой за м² по девелоперу и комнатности с запасным глобальным значением.

Набор меньше первоначально запланированных 1 500–3 000 записей. Он достаточен как стартовый практический срез для EDA, baseline и нескольких ML-экспериментов, но для стабильного сравнения моделей на новых ЖК лучше расширить его до 2 000+ сопоставимых предложений с единой датой и подтверждёнными условиями цены.
