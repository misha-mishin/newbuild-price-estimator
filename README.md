# Newbuild Price Estimator

## Сбор новых объявлений

Данные дополнены двумя публичными каталогами ГК ФСК: «Симоновский Вал» и
«Архитектор». Нужны Python 3.10+ и `curl`; сторонние библиотеки не требуются.
Команды запускаются из корня репозитория.

Снимки страниц сохранены в `data/snapshots/2026-11-19/`. Чтобы повторить
разбор без скачивания:

```bash
python src/collect_fsk.py data/snapshots/2026-11-19 2026-11-19
```

Чтобы скачать свежие страницы (по одному запросу на страницу, без фильтров;
на 19.11.2026 `robots.txt` сайта их не запрещает, при ограничении доступа
его нельзя обходить):

```bash
d=data/snapshots/$(TZ=Europe/Moscow date +%F)
mkdir -p "$d"
curl -fsSL https://fsk.ru/simonovskij-val/flats -o "$d/simonovskij-val.html"
curl -fsSL https://fsk.ru/arhitektor/flats -o "$d/arhitektor.html"
python src/collect_fsk.py "$d" "$(TZ=Europe/Moscow date +%F)"
```

Скрипт извлекает характеристики и опубликованные цены, проверяет, что цена за
м² сходится с ценой и площадью (допуск 2,5%), убирает повторы и сверяет
квартиры с исходным CSV по ЖК, корпусу и номеру (совпадение подтверждается
секцией, этажом и площадью). Спорные случаи останавливают запись.

Перед сравнением цен сборщик проверяет, что площадь, цена предложения
и цена за м² положительны, а этаж находится в пределах от 1 до этажности
дома. Если опубликована цена до скидки, она должна быть выше цены
предложения. При ошибке проверки или спорном совпадении сборщик указывает
проблемную квартиру и не записывает CSV.

Результат — `data/collected/newbuild_prices_fsk_projects.csv` в схеме
исходного файла. Чтобы пересобрать его, сначала удалите существующий файл.

Результат на снимках от 19.11.2026: 39 новых записей (Симоновский Вал — 19,
Архитектор — 20), дублей с исходной выборкой нет.

Проверка воспроизводимости: в чистом клоне на Python 3.13.5 повторный
разбор сохранённых HTML-снимков без обращения к сайту дал 39 строк.
Пересобранный CSV совпал с версией в Git (`git diff --exit-code`).

Ручная сверка со снимками от 19.11.2026: проверены четыре квартиры —
№ 100 и № 135 в ЖК «Симоновский Вал», № 1267 и № 539 в ЖК «Архитектор».
Номер, комнатность, площадь, этаж и этажность, цена предложения,
цена за м² и зачёркнутая цена совпали с CSV.

### Ограничения

- Собрана только первая выдача каталога, остальные квартиры не загружены.
- `finish` и `handover_text` не извлекаются из каталога и
  остаются пустыми, `source_crawled_age` тоже. Это нужно учитывать при
  использовании отделки как признака.
- `discount_pct` рассчитан как `100 × (1 − цена / цена до скидки)`, если
  опубликована цена до скидки.
- `source_url` — страница каталога, а не карточка квартиры.
- На сайте ФСК указано, что права на опубликованные материалы принадлежат
  ГК ФСК. `robots.txt` учитывается при выборе страниц для автоматического
  сбора, но не подтверждает право на распространение материалов.
  Явное разрешение на распространение полных HTML-снимков не найдено.
